# Intermediate Task 03 — SOC Alert Triage

## Overview

In this exercise, I worked with ten **simulated security alerts** to practice reviewing logs, classifying suspicious activity and comparing SOC decisions.

I recorded my own verdicts for **Alerts 01 and 02**. Complete written answers for Alerts 03–10 are available alongside the model's assessments. ChatGPT prepared those eight answers from the same synthetic event details, so they are not independent verdicts. I compared the results and noted limitations in the comparison files.

## Required submissions

I need to submit the ten alert triage answers and a comparison of my verdicts with AI assessments. This Task 03 assignment does **not** request evidence screenshots.
